Comments In C Program

What are Comments?

Comments are text that is not executed in C. These are used by humans so we can explain what certain parts of our code do, add notes and to aid in debugging.
The preprocessor will remove these from the code when it is compiled. This means they have no affect on the size of the executable file, or how well it will run.

Types of Comments in C:

C supports two primary styles of commenting: Single-line and Multi-line.

1. Single-Line Comments (C99 Style):

        Syntax:
            // This is a single-line comment
These are commented lines that were introduced in C99 worldwide.
They start with two forward slashes //.
Any text after // will be ignored by the compiler until the end of the line.
Best used for short comments before statements, or as inline/trailing comments.

Example: 
        #include 

        int main() {
            //Standalone comment
            int age = 25; 

            printf("Age: %d\n", age); // Inline comment
            return 0;
        }

2. Multi-line comment (Traditional C style):


            Syntax:
                  /* Hi,
                         Hello */
Multi-Line Comments are used in the original ANSI C standard (C89).
They start with a forward slash and asterisk and end with an asterisk and forward slash.
All text between these will be ignored.

Perfect for adding proper headers to your files, or detailed explanation on how your algorithm works.
Can also be used to temporarily disable large chunks of code whilst debugging.

Example: 
        #include 

        /* 
        * This is a multi-line comment block.
        * It is highly useful for documenting complex structures,
        * licensing rules, or function parameters.
        */
        void main() 
        {
            printf("Hello World");
        }

Important behavioural rules and traps:

1. No Nested Multi-Line Comments:

You cannot nest multi-line comments. The compiler will match the first closing */ that it finds with the first opening /* that it sees. This will cause problems with your code.

Example:

        /*This is an outer comment
        /* this is an inner comment */  <--The compiler will stop commenting here.
        This will cause a syntax error during compilation. Because this text is visible.*/
