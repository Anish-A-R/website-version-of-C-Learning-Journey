Basic Structure of C Program:

Introduction:

The structure of a C program is the way the components are arranged making it easier to read and understand. C programs often consist of preprocessor directives, declarations, a main() function and user defined functions. These are arranged depending on how they need to be for the specific program. A good structure will make the program easier to develop, debug and maintain.
In the basic structure of a C program, the main() function is the only mandatory component required for a program to compile and run.

This is a simple code to calculate the area of circle.

              

        /* =========================================================
        1. DOCUMENTATION SECTION
        Description: Calculates the area of a circle.
        Author: XYZ
        ========================================================= */



        // 2. PREPROCESSOR SECTION
        #include  

        // 3. DEFINITION SECTION
        #define PI 3.14 

        // 4. GLOBAL DECLARATION SECTION
        float calculate_Area(float radius);

        // 5. MAIN FUNCTION SECTION (Mandatory entry point)
        int main()
        {

            float area;

            printf("The area of the circle is: %.2f\n", area);

        }

        /* =========================================================
        6. SUBPROGRAM SECTION (User-defined functions)
        ========================================================= */
        float calculateArea(float radius)
        {

Documentation Section:

Definition:

A C program will have a section called document. This goes at the top of your source file and contains comments that give information about your program. Although the C compiler ignores this section, it's important to include it so the humans who will be reading, developing and maintaining your code understand what the code does.

What are the things to include in the documentation section?

            A complete enterprise-grade documentation section is broken down into four core logical pillars:
                • Identity & Ownership: Strict metadata defining the file name, author, department, and legal copyright boundaries.
                • Functional Mechanics: Clear, high-level technical documentation explaining what the code does, its dependencies, hardware limitations, and operational complexity.
                • Auditing & History: A clear changelog tracking versions, dates, developer handles, and bug tracking IDs (e.g., Jira ticket numbers).
                • Lifecycle Status: Explicit tags indicating if the code is deprecated, experimental, or thread-safe.

Preprocessor Section:

Definition:

Link / Preprocessor Section is the 1st working part of your C program. It prepares your code for compilation by using external utilities and libraries. Prior to the computer translating your C code into an executable, your file will be scanned top to bottom by a special tool called the Preprocessor. The Preprocessor looks for the Preprocessor Section and runs instructions which begin with a hash (#).

The Anatomy of the Preprocessor Section:

In your code, the section looks like this: 

#include <stdio.h>

This single line consists of two crucial parts:
1. The #include Directive:
This is a direct command to the preprocessor that means, "Go find an external file, copy its entire contents, and paste them right here into my code before compiling."
2. The Header File (<stdio.h>):
This stands for Standard Input Output. It is a built-in system file that acts like a dictionary containing the blueprints for basic commands like printf() (used to print text to the screen) and scanf() (used to read user input from the keyboard).

Common Header Files You Will See in This Section

            Depending on what your program needs to do, you will add different toolboxes to this section:
                • #include <stdio.h>> → For standard input/output (printf, scanf).
                • #include <math.h> → For advanced math operations (square roots, powers, trigonometry).
                • #include <string.h> → For manipulating text strings (copying, joining, or comparing text).
                • #include <stdlib.h> → For memory allocation, random numbers, and process control.
