Tokens

Definition:

C tokens are the smallest elements in a program that have some meaning for the compiler. They can be thought of as the individual words and punctuation of a sentence. When the C compiler is compiling your program it will break it down into tokens before checking any grammar and converting it to machine code.

The 6 Types of Tokens in C:

C classifies every token into one of six main categories:

Token Type Description Examples
Keywords Reserved words which have a fixed meaning and can’t be used as variable names int, return, if, while, void
Identifiers User defined names given to variables, functions and arrays main, total, age, calculateSum
Constants Constant values that do not change during program execution. (Also known as literals) 10, 3.14, 'A', 0x2a
Strings A sequence of characters within double quotation marks. "Hello", "Enter a number"
Operators Symbols that cause mathematical, relational or logical operations to occur +, -, *, =, ==, &&
Special Symbols Punctuation and structural symbols ;, ,, (), {}, []

Example:

Consider this single line of C code:

int sum = 10 + 20;

This statement will be divided into 7 tokens by the compiler as follows: int is a keyword. sum is an identifier. = is an assignment operator. 10 is an integer constant. + is an arithmetic operator. 20 is an integer constant. ; is a special symbol (used to terminate a statement).

Not: Comments are not keywords they come under non-keywords.
