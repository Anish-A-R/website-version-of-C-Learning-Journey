Identifiers

Definition:

Identifiers are unique names created by the user of some element in a C program such as variables, functions, arrays, structures, and labels. They are used to represent memory locations and sections of code where you can store, retrieve and manipulate data.

Rules for Naming Identifiers:

The C compiler has very strict rules about identifying identifiers. If you break any of these rules, then the code will not compile.
1.Allowed characters:
Only uppercase (A-Z), lowercase (a-z), numbers (0-9) and underscores (_) can be used in identifiers.
Must start with letter/underscore, The first character must be a letter or an underscore. Numbers cannot be used at the beginning of identifiers.
2.No reserved keywords:
You cannot use any of the built-in keywords such as int, return, while or void.
3.Case sensitive:
C is case sensitive so uppercase and lowercase letters are treated as separate. For example - total, Total and TOTAL would all be different identifiers.
5.Spaces/hyphens/punctuation/symbols:
Spaces, hyphens, punctuation and symbols such as @, $ or % cannot be used.
4.Unique within scope
No two entities can have the same identifier name in the same scope.

Example:

Character Length Limits

Although modern C compilers support long identifiers, there are minimum standards that specify how many characters a compiler must recognize.
1.C89 / C90 Standard:
Internal identifiers are guaranteed to be recognized up to 31 characters. External identifiers are guaranteed to be recognized up to 6 characters.
2.C99 and Newer Standards:
Internal identifiers are guaranteed to be recognized up to 63 characters. External identifiers are guaranteed to be recognized up to 31 characters.
3.Modern Compilers:
Modern compilers like GCC, Clang and Microsoft C usually support much longer identifiers (often 247 characters or unlimited).
