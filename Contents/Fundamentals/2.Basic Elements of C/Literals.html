Literals

Definition:

A literal is a constant value in programming. They are values you hardcode directly in your code. They are used for storing actual data. A variable is a named storage container which can be changed, a literal is a specific piece of data like 25, 3.14, 'A' or "Hello".

Types of Literals:

There are 4 types of literals in C:
1.Integer Literals:
These are used to represent whole numbers. They can be written in decimal (42), octal (052) using the prefix 0, hexadecimal (0x2A) using the prefix 0x and binary (0b101010) using the prefix 0b in C23. They can have a suffix of u, L or LL.
2.Floating Point Literals:
These are used to represent real numbers. By default they will be stored as double in C but can have a suffix of f to make them float (3.14f) or L to make them long double (3.14L).
3.Character Literals:
Are used to represent a single character, these are surrounded by single quotes ( ' '). For example 'X'. These can also have escape sequences such as '\n'. They are stored as integers (int) in C based on the ASCII code of the character. For example 'A' is 65.
4.String Literals:
This is used to represent a collection of characters. These are surrounded by double quotes ( " "). A null character ( '\0') will automatically be added to the end of all strings by the compiler. This is then stored in read only memory.
