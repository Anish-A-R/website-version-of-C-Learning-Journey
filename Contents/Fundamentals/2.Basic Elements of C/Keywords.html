Keywords

Definition:

Keywords are pre-defined reserved words in C. They hold a special meaning within the compiler. Because they are fundamental to the language syntax you cannot use them as variables, functions, or structures. The classic ANSI C standard (C89/C90) has 32 standard keywords. Newer standards such as C99, C11, C23 have extra reserved words.

The 32 Keywords:

Category Keywords Primary Purpose
Data Types & Modifiers char, double, float, int, long, short, signed, unsigned, void Define the type, size, and sign of data a variable or function holds.
Control Flow & Loops break, case, continue, default, do, else, for, goto, if, return, switch, while Direct program execution through decisions, loops, and jumps.
Storage Classes auto, extern, register, static Control variable scope, memory location, and lifetime.
User-Defined Types enum, struct, typedef, union Group variables together or create custom type aliases.
Type Qualifiers & Operators const, sizeof, volatile Restrict variable modification, prevent compiler optimization, or measure memory size.

Overview:

1.Data Types & Modifiers:

These keywords determine how much memory is allocated to a variable and how the binary data within can be read.
These are the four basic data types:
1.int: Stores whole numbers.
2.char: Stores individual ASCII characters.
3.float: Stores single precision decimals.
4.double: Stores highly precise decimals.


These are used to manipulate the amount of the data stored:
1.short: Used to reduce the amount of memory needed to store a number. For example short int will reduce memory usage for smaller numbers.
2.long: Used to increase memory for very large numbers. For example long int or long double.

These lets you know if your variable can store negative numbers or not:
1.Signed: If a variable is signed it can store positive and negative numbers.
2.Unsigned: Integers use all bits to store 0’s and positive numbers. Doubling the possible max positive number.

This is the last keyword that comes under this category:
Void: It means no type. It is used when a function doesn’t return a value, or has no parameters. It can also be used to create a generic pointer (void ). This can point to any data type.

2.Control Flow and Loops:

The following keywords can be used to control the flow of your code from top to bottom. This allows your programs to make decisions and repeat sections of code.

if/else:
This enables you to use conditional branches. Any code in the if block will only run if the condition evaluates to true. Any code in the else block will run if the condition evaluates to false.

switch/case/default:
This enables you to use multiple branches. The switch statement will evaluate the variable once and will then jump to the correct case label. If none of the cases match then it will go to the default.

for/while/do:
This enables you to loop. While checks the condition first. Do-while will always run once. For is a more compact way of initialising, checking and incrementing. break/continue: This is used to control the flow of your loop. Break will immediately exit the loop or switch block. Continue will skip the rest of the current loop and will go to the next check. return: This will exit the current function and return a value.

goto:
This will unconditionally jump to the labelled statement. Most developers will avoid using goto as it can make your code difficult to read. It is sometimes used in lower level system code to jump to a common error clean up section.

3.Storage Classes:

The storage class defines how large the variable is, how long it can exist for, and where it will be stored.

1.auto:
This is the default storage class for all locally scoped variables declared inside a function. The variable will be created at the start of the function and will be automatically destroyed at the end. This keyword is very rarely typed.
2.static:
This keyword can be used in 2 ways. If it is declared inside a function then it will retain its value between calls. If it is declared outside of a function then it will limit the scope of a global variable/function. By declaring static outside a function the variable/function will only be visible inside the .c file.
3.extern:
This is used to declare a global variable/function which has been defined in another source file. This lets the compiler know the variable already exists somewhere else in memory. This means multiple .c files can access the same data.
4.register:
This is a suggestion to the compiler to store a commonly used variable in a fast CPU register. However modern compilers will allocate registers automatically so this keyword is largely obsolete.

4.User-Defined Types

C has features that allow the programmer to create their own data types.

1.struct:
Structures allow multiple variables to be grouped with different data types. Each variable is stored separately so it is great for representing real-life objects. For example a student records or point co-ordinates.
2.union:
Unions are similar to structs. However, each variable shares the same memory address. As only one variable can have a valid value at any one time unions are used in memory restrictive systems.
3.enum:
Enumerations allow programmers to create their own data type made up of named integer constants. For example (enum Day { MON, TUE, WED }). Enums can be useful when trying to make code less confusing by using readable values instead of numbers.
4.typedef:
This allows you to create an alias for existing data types. This is often used by developers to shorten long declarations. For example struct Student can be shortened to simply Student.

5. Type Qualifiers and Operators

These are keywords that enforce safety rules on variables or allow you to see memory.

1.const:
This forces the variable into a read only state, and any attempt to alter it by any part of your code will cause the compiler to return an error message.
2.volatile:
This keyword informs the compiler that the variable may change suddenly from external sources (hardware sensors, interrupt service routines). The compiler will not store the value in a register but instead constantly reads the value from memory.
3.sizeof:
This keyword seems like a function but is actually a compile time operator. It will tell you the size in bytes of the data type or variable. This is vital when making your code portable and when dynamically allocating memory using functions such as malloc().

Important Rules for Using C Keywords:

1.Case Sensitivity:
C treats uppercase and lowercase letters as separate characters. whilst is a keyword but Whilst or WHILST can be used as variables. However, it is bad practice to do so.
2.No Redefinition:
Keywords cannot be redefined using #define macros. They also cannot be used as function names, variable names or goto labels.
3.Underscored Keywords:
Modern standards of C (C99 to C23) have introduced keywords that start with an underscore and a capital letter (_Bool or _Atomic). This was to prevent problems with existing codebases that had already used these words as variables (e.g. bool).
