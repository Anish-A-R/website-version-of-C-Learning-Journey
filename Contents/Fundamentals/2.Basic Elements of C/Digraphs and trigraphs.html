Digraphs and trigraphs.

Definition:

Digraphs and trigraphs in C are two- and three-character sequences that represent single punctuation characters or operators. They were originally created for older keyboards and international character sets (such as ISO-646 or IBM mainframes) that lacked symbols like {, }, [, ], and #.

Trigraphs (Three-Character Sequences):

Trigraphs are sequences beginning with two question marks (??). They are expanded in the very first stage of compilation - even before comments or string literals. This means they are expanded unconditionally everywhere and can lead to obscure bugs if you have two question marks in a row, like "What??!" which will become "What|".

Trigraph Equivalent Character Character Name
??= # Number sign (hash)
??/ \ Backslash
??' ^ Caret
??( [ Left square bracket
??) ] Right square bracket
??! | Vertical bar (pipe)
??< { Left curly brace
??> } Right curly brace
??- ~ Tilde

Note:

Trigraphs have been officially deprecated in C-23 and are disabled by default in modern compilers, such as GCC and MSVC. They can be enabled using - trigraphs or /Zc:trigraphs.

Diagraphs(Two Character Sequence)

Digraphs were introduced in C95 and standardized in C99. They allow you to replace trigraphs safely and cleanly. Digraphs are processed during tokenization meaning that if they appear within string literals, character constants or comments they will not be replaced.

Digraph Equivalent Token Description
<: [ Left square bracket
:> ] Right square bracket
<% { Left curly brace
%> } Right curly brace
%: # Number sign (preprocessor directive)
%:%: ## Preprocessor token pasting
