Data Types

Definition:

Data types are used in C programming that tells what kind of data a variable can hold. For example, integer, float, character, etc. Data types also tell the compiler how much space needs to be allocated for variables, and how to interpret the bits stored in binary form.

This is just a overview... Dont get stressed by seeing them we will explore deeper in the future...

Different Types:

1. Basic (Primitive) Data Types:

These are basic types that can be used to store simple data. Depending on your system architecture (such as 32-bit or 64-bit) the size may vary slightly. However, they should be as follows by default.

Data Type Size Format Description Example
int 4 bytes %d or %i Used to store whole numbers. int age = 25;
float 4 bytes %f Used to store fractional numbers (single precision, up to 6-7 decimal places). float price = 19.99;
double 8 bytes %lf Used to store fractional numbers (double precision, up to 15 decimal places). double pi = 3.1415926535;
char 1 byte %c Used to store one character/letter/ASCII value surrounded by single quotation marks. char grade = 'A';

2. Derived Data Types:

Derived data types are formed from basic data types and allow for advanced functionality.
Arrays -
A fixed sized list of elements all of the same data type (int scores[5];).
Pointers -
Store the memory location of another variable (int ptr = &age;).
Functions -
A block of code which can be reused and will return a particular data type (int add(int a, int b)).

3.User-Defined Data Types:

C allows for the creation of user-defined data types to store related information.
Structure (struct):
This stores multiple variables of varying data types within one structure. For example, we can store information about a student such as their name (char[]), age (int), GPA (float).
Union (union):
Works similar to a struct but all members of the union occupy the same location in memory. Therefore only one member can have a value at once.
Enumeration (enum):
Used to create readable names for integer constants. (enum Days {MON, TUE, WED};)

4.The void Data Type

Void means no value. There are 3 main uses for it:
Function Return Type:
Means that a function will have no return value.
Function Parameters:
Means that a function will not take any arguments.
Generic Pointers:
A void pointer can store the memory address of any data type.
