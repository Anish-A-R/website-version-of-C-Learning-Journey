Identifiers

Definition:

A variable in C is a named storage unit in computer memory. Variables are used to hold mutable data. All variables have a data type which describes how much memory they take up and what kind of data they can contain.

Operations with Variables:

Key operations when dealing with variables are,
1.Declaration - Tells the compiler the name of the variable. Also tells the compiler what type of data the variable is. This means the compiler will allocate space in memory. As no value is given, the variable will contain random rubbish data.
2.Initialisation - Assigns an initial value to the variable when declaring the variable. This will ensure that the variable has a known safe value.
3.Assignment - This is used to update the value of an existing variable. You can change the value of a variable as many times as you like using the = operator.
