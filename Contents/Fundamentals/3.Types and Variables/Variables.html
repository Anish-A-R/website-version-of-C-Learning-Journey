Identifiers

Definition:

A variable in C is a named storage unit in computer memory. Variables are used to hold mutable data. All variables have a data type which describes how much memory they take up and what kind of data they can contain.

Operations with Variables:

Key operations when dealing with variables are,
1.Declaration - Tells the compiler the name of the variable. Also tells the compiler what type of data the variable is. This means the compiler will allocate space in memory. As no value is given, the variable will contain random rubbish data.
2.Initialisation - Assigns an initial value to the variable when declaring the variable. This will ensure that the variable has a known safe value.
3.Assignment - This is used to update the value of an existing variable. You can change the value of a variable as many times as you like using the = operator.

Simple Example: 

        #include <stdio.h>
        void main() {

            int num; //Declaration
            num = 10; //Assignment
            num = 20; //Re-Assignment

            int temp = 100; //Initialisation

        }

Variable Declaration:

Declaration is when you give a variable a data type and name so the C compiler knows how much memory to allocate.
Syntax:

            data_type varible_name; //For single declaration 
            data_type var1,var2,...; //For mutiple declaration
The OS will allocate the correct amount of bytes of memory. However, it will not wipe what was in there. Any remaining binary data will remain in that section of RAM. This is known as a garbage value. If you try to read an uninitialised variable you will get unpredictable bugs.
You can declare multiple variable of the same type on the same line by separating them by commas.

Variable Initialization:

Initialisation is simply giving a variable a starting value during declaration.
This is important as it will overwrite any random garbage value stored in that location of memory. Almost every good C programmer will initialise their variables immediately as it helps to avoid any accidental errors.
Syntax: 

            data_type variable_name = initial_value;

Variable Assignment:

Assignment is the name given to putting a new value into an existing variable in memory. This is done using the single equals sign (=) which is known as the assignment operator.
Flow:
Note that " = " in C does NOT mean equals, it means take the value on the right of the equals sign and put it into the memory location on the left.
Overwriting:
The new value will totally overwrite the old value in the memory block.

Some Concepts For Deeper Understanding

Lvalues And Rvalues:

Every time you assign a variable, you're using lvalues and rvalues:
lvalue:
Expressions that represent memory locations (i.e., variables like x). These can be on either side of =.
rvalue:
Temporary values that have no memory address (i.e., constant values like 5 or mathematical expressions like x + 2). These can only be on the right-hand-side of =.
Why 5 = x; won't work:
Because 5 is an rvalue and has no memory box to put x into. (This is why C programmers will sometimes write if (5 == x) rather than if (x == 5). If they accidentally write if (5 = x), then they get a compiler error instead of silently overwriting x!)

Chained Assignment and Right-to-Left Associativity:

Assignments are expressions in C.
The assignment expression x = 5 evaluates to the value assigned. The " = " operator also has right to left associativity.
This means a = b = c = 10; is parsed to a = (b = (c = 10)); However you can not do this when initialising variables.
int a = b = c = 10; will not compile unless b and c have been declared earlier. Instead, you would need to write int a = 10, b = 10, c = 10; 

           include <stdio.h>
           void main()
           {
            /* 
             int a = b = c = 10;
             This will cause an error
             But, The one below will not as we declared b, c and d
            */
            int b,c,d;
            int a = b = c = d =10;
            printf("%d %d %d %d", a,b,c,d);
           }

Comma Operator In Assignment:

The comma , acts as an operator that evaluates expressions from left to right and returns the last value. 

        int x;
        x = (1, 2, 3); // Equalates 1, then 2, then assigns 3 to x.
